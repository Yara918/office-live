# 常见问题速查

## 生成类

| 问题 | 处理 |
|---|---|
| 人超过 8 个 | 生成前提前告知上限，按 8 人交付（本 Skill 面向 8 人以内小团队） |
| 表格打不开/无权限 | 确认链接可读；只读可生成，写回需当前账号对表格有编辑权限（自己的表天然满足，别人的表需「互联网上获得链接的人可编辑」） |
| 页面能看但写回失败（91403 / 写回被拦） | 当前表格可能是只读/可阅读权限，未开启编辑权限。请在表格右上角「分享」中，把权限改为「互联网上获得链接的人可编辑」，保存后刷新页面，即可使用写回功能 |
| 用户不回复确认问题 | 不空等；先说明"等待确认后再生成"，不默默耗时 |

## 技术类

| 问题 | 处理 |
|---|---|
| 构建失败（依赖错误） | 看构建日志，通常为依赖/环境问题，按日志修 |
| 生成时未弹授权链接 | 检查 lark-cli 是否已安装；deliver.mjs 会自动检测授权态并弹出扫码链接，未弹出多为 lark-cli 缺失，安装后重跑 |
| 首次生成要授权 | 正常：deliver.mjs 自动弹出飞书授权链接，扫码 → 网页点「同意」即可（一次性，约 10 秒，无需安装软件） |
| 页面数据不更新 | 确认 baseToken/表 ID 正确；页面轮询同步，等一会或刷新 |
| 转任务不生效 | 确认负责人字段映射正确；确认当前账号对表格有编辑权限（写回权限依赖它） |
| 转任务报字段格式错误 | 按负责人列真实类型处理：文本写姓名，人员字段写用户身份，关联字段写目标记录 ID；lookup/公式/自动编号等只读列只能展示，不能写回 |
| 新增任务失败 | 看提示指向的具体字段（如「选项不在可选范围」「没有编辑权限」）；确认当前账号对表格有编辑权限 |
| lark-cli 找不到 | 确认已安装并加入 PATH；`LARK_CLI_BIN` 仅用于指定安装位置，禁止用它换有旧授权的二进制绕过扫码（授权一律走 deliver 弹码扫码） |

## 访问类

| 问题 | 处理 |
|---|---|
| 本地页面打不开 | 用「隐藏窗口 + 独立进程」方式启动服务（Windows VBScript / macOS launchd，见 deployment.md「启动页面」），验证首页 200 与快照 `source: feishu` 后再交付地址 |
| 3000 被占用 | 使用 `deliver.mjs` 自动选择的新端口，并按该端口启动和验证，不能误连旧服务 |
| 页面加载慢 | 首次加载需下载素材（数 MB），可接受 |

## 权限类

| 问题 | 处理 |
|---|---|
| 员工点 E 弹验证 | 正常：管理操作需口令，员工无口令只能看 |
| 口令忘了 | 口令 = 表格名称（生成时默认）；可改配置 adminCode 重新生成 |
| 刷新后又要输口令 | 正常：口令为会话级，刷新/新设备需重输 |
