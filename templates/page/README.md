# Office Live 小剧场（页面模板）

由飞书多维表格数据驱动的像素风办公室互动小剧场。

## 功能

- **像素办公室**：成员以像素角色在地图中走动、互动，直观展示工作状态
- **数据驱动**：任务/成员/项目/风险/里程碑均来自飞书多维表格，页面与表格双向同步
- **管理操作**：调整负责人、安排任务、新增任务需管理口令（默认取表格名称）
- **互动玩法**：展开互动面板，让成员喝水、开会、站会、摸鱼等

## 快速开始

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000

## 配置

每次交付只改 `lib/office-config.ts`：填写客户的 Base token、表 ID、字段映射和管理员姓名。换客户表格 = 换配置，代码不动。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | Next.js + React + TypeScript |
| 游戏 | Phaser 3 像素场景 |
| 数据 | 飞书多维表格 OpenAPI |
